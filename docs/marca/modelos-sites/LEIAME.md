# Modelos de páginas por segmento (IM-091)

Coloque aqui os modelos prontos enviados pelo Emerson, uma subpasta por estilo:

`docs/marca/modelos-sites/<numero>-<estilo>/`, por exemplo `06-cafe-e-padaria/` ou `13-imobiliario/`.

Formatos aceitos: imagem (PNG/JPG), PDF ou HTML. Se possível, uma imagem para celular e outra para computador.
Estes arquivos são referência de design; a interface adequa a partir deles. Não contêm dados reais nem segredos.
